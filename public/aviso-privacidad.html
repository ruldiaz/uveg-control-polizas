Aviso de Privacidad

Última actualización: 16 de octubre de 2026.

Responsable y alcance

RHDF - Sistema para control de seguros es una aplicación desarrollada con fines académicos y de organización personal. No es una aseguradora, no intermedia contratos de seguro y no sustituye los documentos oficiales emitidos por las instituciones aseguradoras.

Datos que se recopilan

La aplicación puede almacenar los siguientes datos proporcionados por la persona usuaria:

  • Número de póliza.
  • Nombre de la aseguradora.
  • Nombre de la persona asegurada o aseguradas.
  • Tipo de seguro.
  • Fecha de vencimiento.
  • Suma asegurada.

Finalidad del tratamiento

Los datos se utilizan únicamente para registrar, consultar y organizar información de pólizas dentro de la aplicación. No se venden, comparten ni utilizan con fines comerciales.

Conservación y eliminación

La información se conserva mientras la persona usuaria la mantenga registrada en la aplicación. Cada póliza se puede eliminar desde el listado de pólizas; esta acción elimina el registro correspondiente de la base de datos de la aplicación.

Publicidad, rastreo y permisos

RHDF no muestra publicidad, no incluye rastreadores ni comparte datos con terceros con fines publicitarios. La versión Android solo requiere acceso a Internet para comunicarse con el servicio de la aplicación; no solicita acceso a cámara, ubicación, micrófono, contactos, llamadas ni almacenamiento compartido.

Medidas de protección

La aplicación aplica validación de datos, acceso mediante una conexión HTTPS y almacenamiento en una base de datos PostgreSQL. Las credenciales de acceso se mantienen fuera del código publicado. Para este entorno de práctica se deben usar datos ficticios.

Uso responsable

La persona usuaria es responsable de capturar únicamente información para la que cuente con autorización y de proteger el acceso al equipo donde se ejecuta la aplicación.

Contacto
